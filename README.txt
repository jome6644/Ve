VEZXOXO NETLIFY FORMS

This version uses Netlify Forms only.

No email setup is required.
No Supabase is used.
No custom database is used.
No serverless function is required.

Setup:
1. Upload all files to GitHub.
2. Deploy the repository on Netlify.
3. In Netlify, open Forms.
4. Enable form detection if it is not already enabled.
5. Redeploy the site once after enabling form detection.
6. Submit a test application.
7. Open Forms > talent-application to view all answers.

The form is named:
talent-application
